English

1. What this app is

YouTube MCP is a personal tool that runs only on the owner's own computer. It uses YouTube API Services to manage the owner's own YouTube channels.

2. Data accessed

With your authorization through Google OAuth, the app accesses:

  • Basic YouTube channel information (channel ID, title, statistics).
  • Videos, playlists, captions and thumbnails of your channel — to upload, list, update or delete them when you request it.

The app does not access Gmail, Google Drive, contacts or any other Google data.

3. How data is used

Data is used only to carry out actions you explicitly request (e.g. "upload this video", "add it to this playlist"). It is not used for advertising, profiling, analytics or AI model training, and it is never sold.

4. Storage

OAuth tokens and the channel list are stored only on your own computer in local files. There is no server operated by this app and no data is sent to any third party other than Google/YouTube through the official API.

5. Sharing

No user data is shared with, transferred to or sold to any third party.

6. Revoking access & deletion

You can revoke access at any time at Google Account → Third-party connections (or via the Google security settings page). Deleting the local tokens/ folder removes all stored credentials.

7. Google API Services User Data Policy

YouTube MCP's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

8. YouTube

This app uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.
